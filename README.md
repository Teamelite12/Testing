# Accessibility Testing

## Overview
This repository contains tools and resources for web accessibility testing. The project aims to help developers ensure their web applications are accessible to all users, including those with disabilities.

## Purpose
The main goals of this project are:
- Provide sample HTML files for accessibility testing
- Demonstrate proper accessibility implementation
- Help developers test and validate web accessibility compliance

## Contents
- `sample.html` - Sample HTML file for accessibility testing experiments

## Usage
1. Clone this repository
2. Open the sample files in your browser
3. Use accessibility testing tools to validate compliance
4. Reference the examples for implementing accessible web content

## Accessibility Standards
This project follows Web Content Accessibility Guidelines (WCAG) principles:
- Perceivable
- Operable
- Understandable
- Robust
